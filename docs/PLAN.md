## 1. 레퍼런스에서 배운 것 (코드로 확인한 것만)

### ① 에셋을 사지 않고도 퀄리티가 나온다

전차 112종이 **전부 절차적 지오메트리**다. 외부 GLB는
`"quarantined research references; never loaded as playable geometry"`.
텍스처도 전부 코드다 — `materials.js`는 2048px 알베도를 캔버스에 그린다

→ 우리의 "유료 에셋이 필요하다"는 전제가 틀렸다.

## 3. 분담 (확정)

**Claude = 시각·에셋 / Codex = 시스템**

| Claude (시각·에셋) | Codex (시스템) |
|---|---|
| 렌더 파이프라인 (`engine/` 분리, post 체인, 품질 티어) | 전투 판정·스킬 판정·상태 머신 |
| 절차적 몹·아이템 팩토리 (지오메트리 + 캔버스 텍스처) | 적 AI (돌진형·정예·보스 패턴) |

| 시각 QA 도구 (contact sheet, 실루엣, 그림자 감사) | 시나리오 하니스 위의 전투 밸런스 |

**경계 규칙 (유지)**: 한 파일은 한 사람. `core/world.ts`·`main.ts`·`ui/hud.ts`는 추가만.
쓰기 전에 보드에 올린다.

**인계 프로토콜 (신규)**: 스킬 하나를 붙일 때
1. Codex가 **판정 + 이벤트만** 확정 (`SkillCastEvent`, 애니메이션 상태)
2. Claude가 **연출 전부**를 한 번에 연결 (VFX·사운드·카메라·HUD)
3. 시나리오 테스트 1건 + 녹화 1회
4. 보드 한 줄

## 4. 텍스트 RPG 시나리오 하니스 (신규, 오늘 완성)

`src/scenario/` + `tests/scenario.*.test.ts`. `npm run scenario`.

브라우저 없이 **진짜 전투 루프**를 돌린다. `main.ts`의 `logic()`과 같은 시스템 순서로
고정 60Hz 스텝을 밟고, 상태 변화를 텍스트로 뽑는다.

```
── 갱도 진입 ─────────────────────────────────────────
   존 mine · HP 100/100 · 분노 0 · Lv.1 · 위치 (32.0, 52.0) · 적 8
   #######···#########
   ···········########
   w······a···########
   ###······@······###

── 교전 ────────────────────────────────────────────
[  5.68] 휘두른다 · 나 (95/100)
[  5.68] 명중 · archer#1 (17/25)
[  5.82] 명중 · archer#1 (5/25)
[  7.37] 쓰러뜨렸다 · archer#1 (0/25)
[  7.37] 전리품이 떨어졌다
```

**설계 원칙**
- 조작은 **실제 의도 컴포넌트로만** (`attackIntent`/`moveTarget`/`skillIntent`).
  좌표를 손으로 옮기는 함수는 두지 않았다 — 그건 검증이 아니라 치팅이다.
- 이벤트는 `combatEvents`에서 온다. **소리·이펙트와 같은 신호**다 —
  텍스트에 안 찍히면 소리도 안 난다는 뜻이 된다.
- 이벤트에 발생 시각·체력을 박제한다. 처음엔 나중에 읽었더니 11줄이 전부 같은 시각으로
  나와 "한 프레임에 11번 맞았다"처럼 읽혔다.
- 난수는 시드. 같은 시드 = 같은 전투.

**만들자마자 잡은 것 2건**
1. `combat.ts` → `worldToScreen` → `window` 의존 (헤드리스에서 전투 자체가 안 돌았다)
2. 내 잘못된 전제 — "가만히 있으면 적이 온다". 실제로는 스폰(32,52)에서 최근접 적이
   12.6, 어그로 10. **입구 방은 설계상 안전지대**였다. 브라우저였으면 60초, 여기선 4초.

## 5. 앞으로 (7~10 작업일, 목표는 하나)

> **마을 → 갱도 → 교전 3회 → 정예 → 보스 → 보상 → 귀환**

이 루프가 닫히기 전까지 다른 존·NPC 확장·아이템 카탈로그·패널은 **동결**.

### Claude 순서

1. **회전베기 연출 완성** (진행 중 — VFX·사운드·카메라 붙음, 녹화 검증 남음)
2. **포스트 체인** — Bloom + SMAA + OutputPass. 툰 룩에 블룸이 가장 크게 먹는다.
   GTAO는 툰에 과하므로 보류.
3. **돌진 연출 완성**
4. **절차적 몹 팩토리** — 근접/원거리/돌진 3종 실루엣 차별화 (Codex의 `EnemyKind` 대기)
5. **보스 1종** — 크기·형태·색·텔레그래프
6. **절차적 아이템 팩토리** — 부위 3종 × 등급 3종 형태 구분
7. **시각 QA 도구** — 실루엣 대조 시트, 그림자 감사

### Codex 순서

1. 준비동작·넉백·히트스톱 (진행 중, 준비동작은 착지 확인됨)
2. `SkillCastEvent` + 스킬 애니메이션 상태 계약
3. 돌진형 `EnemyKind` + 정예 1종 실제 작동
4. 갱도 끝 → 보스방 직결
5. 보스 처치 → 보상 → 마을 귀환

### 매일의 합격 기준

"오늘 몇 줄 썼나"가 아니라 **"오늘 완성된 10초 전투 영상이 나왔나"**.
스킬 하나의 완료 = 입력 → 애니메이션 → 판정 → 전진/넉백 → 고유 VFX → 고유 사운드
→ 카메라 → HUD → 실제 녹화. 하나라도 빠지면 미완성이다.
