## 1. 지적 6건 — 원인 판정

> 질문: 프로토타입이라 그런가, 마땅한 에셋이 없어서인가?
> **답: 6건 중 5건이 프로토타입 문제다. 에셋 부족은 맵 차별성 하나뿐이고, 그것도 절반이다.**

| # | 증상 | 확인된 원인 | 성격 |
|---|---|---|---|
| 1 | NPC가 안 보인다 | `ModelKind`에 `npc`가 없다. `TOWN_NPCS` 7명은 **순수 데이터**이고 엔티티가 생성되지 않는다. 마을 엔티티 수 실측 **2개**(플레이어+동료). 문지기도 좌표로만 존재 | 프로토타입 |
| 2 | 보스 잡고 돌아갈 방법이 없다 | 출구 타일은 있는데 **표식도 힌트도 없다**. 게다가 맵마다 위치가 다르다 — 왕좌는 스폰 칸(14,18)이 곧 출구라 실수로 나가지고, 납골당은 스폰(15,25)과 출구(20,2)가 완전히 딴 곳이라 되돌아가도 안 나간다 | 프로토타입 |
| 3 | 맵이 다 똑같아 보인다 | `FLOOR_BY_MAP` 8개 중 **7개가 같은 타일**(`floor_tile_large`). 벽 변주는 전 맵 공용 3종. 조명·안개는 전 맵 단일 팔레트 | **절반 에셋 / 절반 프로토타입** |
| 4 | 단축키가 인벤토리뿐 | 바인딩이 WASD·좌우클릭·Space(돌진)·I(인벤)·E(상호작용)뿐. **맵·상태창·스킬창 패널 자체가 없다** | 프로토타입 |
| 5 | 아이템에 개성이 없다 | 모든 전리품이 같은 팔면체 보석이고 **등급 색만** 다르다. 아이콘 없음. 장착해도 캐릭터 외형이 안 변한다(부착점 없음) | 프로토타입 + 일부 에셋 |
| 6 | 시점·줌이 안 바뀐다 | `CAMERA_OFFSET`이 모듈 상수(0, 16, 7). 휠 핸들러도 회전도 **없다** | 프로토타입 |

**요약: 에셋을 더 사도 5건은 안 고쳐진다.** 만들지 않은 것이지 못 만든 게 아니다.

부수 수확: `/favicon.ico` 404를 잡아 고쳤다. 브라우저가 자동 요청하는 거라 우리 플레이테스트의
"콘솔 에러 0건" 판정을 오염시키고 있었다. 검증 신호를 깨끗이 두는 게 목적이다.

## 2. 무엇이 프로토타입과 게임을 가르는가

기능 개수가 아니다. 아래 다섯 가지가 성립하면 프로토타입을 벗어난다.

1. **읽힘** — 화면만 보고 어디로 갈지, 뭘 얻었는지 안다
2. **조작** — 원하는 걸 원할 때 한다 (카메라, 단축키, 복귀)
3. **차이** — 두 번째 던전이 첫 번째와 다르게 느껴진다
4. **보상 체감** — 아이템을 먹었을 때 뭐가 달라졌는지 보인다
5. **한 판의 마무리** — 던전을 끝냈다는 신호와 다음 판을 시작할 이유가 있다

지금 다섯 개 다 안 된다. 6건의 지적이 정확히 여기에 꽂힌다.

## 3. 작업 목록 (효과/비용 순)

### P0 — 없으면 플레이가 성립하지 않는다

| 항목 | 내용 | 비용 |
|---|---|---|
| **마을 귀환 수단** | 단축키(T) 또는 상시 버튼. 던전 어디서든 마을로. 지금의 "보이지 않는 출구 타일"에 의존하지 않는다 | 낮음 |
| **출구 표식** | 출구 칸에 시각 표식 + 근접 시 힌트. 왕좌의 **스폰=출구** 겹침도 함께 정리 | 낮음 |
| **NPC 렌더링** | `ModelKind`에 `npc` 추가, `TOWN_NPCS` 7명을 엔티티로 생성. **에셋은 이미 있다** | 낮음 |
| **카메라 줌·회전** | 휠 줌(거리 제한), 우드래그 또는 Q/E 회전. `CAMERA_OFFSET`을 상태로 승격 | 낮음 |

### P1 — 게임처럼 느껴지게 하는 것

| 항목 | 내용 | 비용 |
|---|---|---|
| **존별 분위기** | `theme.ts`를 존별 팔레트로 확장. 수로는 푸르고 축축하게, 왕좌는 붉고 장엄하게, 갱도는 흙빛으로. **에셋 없이 조명·안개·바닥색만으로 맵 인상이 완전히 갈린다. 가장 싸고 효과가 크다** | 낮음 |
| **단축키 + 패널** | M(맵), C(상태), K(스킬), T(귀환), Esc(닫기). 키 안내를 화면에 노출 | 중간 |
| **미니맵** | 탐색 방향 감각. 맵이 텍스트 격자라 만들기 쉽다 | 중간 |
| **던전 클리어 신호** | 보스 처치 후 결과 표시 + 귀환 유도 | 낮음 |

## 4. 권하는 순서

**P0 네 건을 먼저 한 덩어리로 끝낸다.** 전부 비용이 낮고, 넷을 합치면 "조작이 답답하다"는
느낌이 통째로 사라진다. 그 다음 **존별 분위기** 하나만 해도 "맵이 다 똑같다"가 해소된다.
여기까지가 체감 대비 가장 싸다.

아이템 외형(P2)은 마지막이다. 비싸고, 그 전에 할 게 많다.

### 분담 제안

- **Claude**: 존별 분위기 팔레트, NPC 렌더링, 출구 표식, 아이템 아이콘 — 콘텐츠·비주얼 축
- **Codex**: 카메라 조작, 단축키·패널 골격, 마을 귀환, 미니맵 — 시스템·입력 축
