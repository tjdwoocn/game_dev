# ARPG Prototype (Diablo 4-like) — v0 Design Spec

날짜: 2026-08-24
상태: 승인됨 (설계 1/2, 2/2 채팅 승인 완료)

## 목표

디아블로4를 참고한 3D 탑뷰(쿼터뷰) 싱글플레이 ARPG의 **실행 가능한 v0 프로토타입**.
로컬 웹 환경(`npm run dev` → 브라우저)에서 실행. 이후 지속적으로 확장할 수 있는 기반 구조를 갖춘다.

## 확정된 결정

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 — Three.js + TypeScript + Vite |
| 아키텍처 | ECS (miniplex 2.x) + 순수 함수형 시스템 모듈 |
| v0 범위 | 클릭 이동, 기본 공격, 스킬 3종, 루트/장착, XP/레벨업, 일반 적 2종, 보스 1종 |
| 비주얼 | CC0 로우폴리 glTF 에셋(KayKit/Quaternius) + 어두운 조명. 에셋 없이도 프리미티브로 항상 실행 가능 |
| 맵 | 수제작 던전 1개 (입구 → 전투방 2~3개 → 보스방), 격자 데이터 정의 |
| 클래스 | 전사(근접) 1종 |
| 커밋 | 사용자가 직접 수행 (AI는 커밋하지 않음) |

## 기술 아키텍처

### 프로젝트 구조

```
arpg-prototype/
├─ index.html              # HUD 오버레이 DOM 포함
├─ public/assets/          # glTF 모델, 애니메이션 (드롭인 교체 가능)
├─ src/
│  ├─ main.ts              # 부트스트랩: 렌더러, 루프 시작
│  ├─ core/
│  │  ├─ world.ts          # miniplex World 생성, Entity 타입 정의
│  │  ├─ loop.ts           # 고정 스텝(60Hz) 로직 + 가변 렌더 루프
│  │  └─ assets.ts         # glTF 로더, 애니메이션 클립 레지스트리, 프리미티브 폴백
│  ├─ systems/             # 매 프레임 실행되는 순수 로직 (ECS 시스템)
│  │  ├─ input.ts          # 마우스 픽킹 → 이동목표/스킬 의도 컴포넌트 부여
│  │  ├─ movement.ts       # 이동, 격자 벽 충돌, 유닛 간 원형 밀어내기
│  │  ├─ ai.ts             # 적 상태머신: 대기→인지→추적→공격→복귀
│  │  ├─ combat.ts         # 공격 판정, 데미지, 사망 처리
│  │  ├─ skills.ts         # 스킬 발동, 쿨다운, 분노 자원 관리
│  │  ├─ loot.ts           # 드롭 생성, 줍기, 장착 스탯 반영
│  │  ├─ progression.ts    # XP, 레벨업
│  │  ├─ animation.ts      # 상태 → 애니메이션 클립 전환
│  │  └─ render.ts         # 씬 그래프 동기화, 카메라 추적, 체력바 투영
│  ├─ content/             # 데이터 정의 (로직과 분리)
│  │  ├─ skills.ts         # 스킬 3종 수치
│  │  ├─ enemies.ts        # 일반 적 2종/보스 스탯
│  │  ├─ items.ts          # 아이템 테이블, 등급, 접사
│  │  └─ map.ts            # 던전 격자 레이아웃, 스폰 배치
│  └─ ui/
│     └─ hud.ts            # HP/분노 구슬, 스킬바, 인벤토리 패널 (HTML/CSS)
```

### ECS 설계

- 엔티티 = 평범한 JS 객체, 컴포넌트 = 속성. 예: 적 = `{ transform, health, ai, attack, lootTable, model }`
- 시스템은 `world.with("transform", "health")` 아키타입 쿼리로 순회
- 시스템은 순수 함수형 모듈. 상태는 world + 소수의 리소스 객체(입력 상태, 시간)에만 존재
- 게임 루프: 고정 타임스텝 60Hz 로직 / 가변 렌더 분리

### 렌더링·연출

- 어두운 앰비언트 + 플레이어 중심 포인트라이트(횃불 느낌), 안개, 비네트
- 쿼터뷰 고정각 카메라(약 50° 내려다봄), 플레이어 부드럽게 추적
- 히트플래시(머티리얼 점멸), 데미지 플로팅 텍스트

### 에셋 파이프라인

- CC0 로우폴리 glTF (KayKit Dungeon/캐릭터, 대안 Quaternius)를 `public/assets/`에 배치
- 다운로드 자동화 불가 시: 프리미티브 + 절차적 머티리얼로 전부 동작하는 상태를 우선 구현,
  에셋 파일을 폴더에 넣으면 자동 교체 로드되는 레지스트리 구조

### 충돌·물리

- 물리엔진 없음. 맵은 격자 통행 판정, 유닛 간은 원형 충돌 밀어내기

### UI

- HTML/CSS 오버레이: HP 구슬(좌), 분노 구슬(우), 중앙 하단 스킬바, `I` 인벤토리 패널
- 적 머리 위 체력바는 3D→2D 투영 좌표 배치

## 게임플레이 설계

### 전투 기본기

- 좌클릭: 지면 → 이동 / 적 → 사거리까지 접근 후 기본 공격
- 기본 공격이 분노 생성. 근접 판정은 전방 부채꼴
- 적 사망: 사망 연출 → 드롭 생성 → 제거
- 플레이어 사망: "당신은 죽었습니다" 오버레이 + 입구 부활

### 스킬 3종 (전사) — `content/skills.ts`

| 스킬 | 키 | 자원/쿨다운 | 효과 |
|---|---|---|---|
| 휘두르기(기본) | 좌클릭 | 분노 +10 생성 | 전방 부채꼴 타격 |
| 회전베기 | 우클릭 | 분노 25 소모 | 자기 중심 360° 범위 공격 |
| 돌진 | Space | 쿨다운 5초 | 지정 방향 대시, 경로상 적 피해+넉백 |

### 아이템·루트

- 등급 3단계: 일반(흰)/마법(파랑)/희귀(노랑). 드롭 시 등급색 빛기둥 + 이름표
- 슬롯 3종: 무기/갑옷/반지
- 아이템 = 기본 스탯 + 등급별 랜덤 접사 0~2개 (공격력 +N, 최대HP +N, 이동속도 +%)
- 클릭 줍기 → 인벤토리 클릭 장착/교체 → 파생 스탯 일괄 재계산

### 성장

- 처치 시 XP, 단순 지수식 레벨 곡선
- 레벨업: 공격력/최대HP 증가 + 전체 회복 + 황금빛 이펙트. 스킬포인트는 v1 이후

### 적·보스

- 근접형(스켈레톤 워리어): 추적 후 근접 공격
- 원거리형(스켈레톤 아처): 거리 유지 + 투사체
- AI 5상태: 대기→인지→추적→공격→복귀
- 보스: 고체력 + 패턴 2개 — ① 예고 후 3연속 광역 강타 ② 경로 표시 후 돌진 차지
- 보스 처치: 희귀 확정 드롭 + "던전 클리어"

### 던전

- 입구홀 → 복도 → 전투방 2~3개 → 대형 보스방. 1회차 약 5분
- 격자 데이터에서 벽/바닥 메시 자동 생성 (에셋 있으면 타일 모델, 없으면 박스)

## 테스트·검증

- Vitest 단위 테스트: 데미지 계산, XP 곡선, 접사 굴림, 스탯 재계산, AI 상태 전이 등 순수 로직
- 스모크 체크: 브라우저 자동화로 실행 → 콘솔 에러 없음 → 플레이어 이동 확인
- 조작감·연출은 사용자 직접 플레이 확인

## 구현 마일스톤 (각 단계 실행 가능 상태 유지)

1. 프로젝트 셋업 + 루프 + 맵 렌더 + 클릭 이동 + 카메라
2. 적 AI + 기본 공격 + 체력/사망 + HUD
3. 스킬 3종 + 자원/쿨다운
4. 루트/인벤토리/장착 + XP/레벨업
5. 보스 + 클리어 연출 + 에셋/조명 폴리시

## v0 범위 제외 (이후 마일스톤)

- 절차적 던전 생성, 추가 클래스, 스킬트리/스킬포인트, 상점/제작, 저장/불러오기,
  사운드, 추가 부위 슬롯, 물약/포션 시스템
