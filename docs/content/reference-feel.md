## 옮길 것 (값어치순)

### A. 바닥의 명암 띠 — **비용 대비 최고**

`ref/moon-04-floor-bands.jpg`

바닥이 화면의 60% 이상인데, **차가운 회색 판과 따뜻한 주황 판이 띠 모양으로 교차**한다.
텍스처가 아니라 **톤**이다. 이 띠가 공간을 나누고 "빛 드는 곳 / 그늘"을 만들어서,
아무 구조물이 없는 넓은 바닥도 심심하지 않다.

우리 바닥은 같은 타일을 균일하게 반복한다. `dungeonDressing.ts` 가 이미
`InstancedMesh.setColorAt` 을 쓰고 있으므로 **드로우콜 증가 0, 신규 에셋 0** 으로 적용된다.

### B. 타격 이펙트가 4~5겹이다

`ref/moon-03-impact.jpg`

한 번의 명중에 겹치는 것:
1. 흰 코어(과노출)
2. 방사형 스파크 선 — 짧고 얇게 사방으로
3. **확장하는 흰 링 외곽선** ← 이게 핵심
4. 주황 연기 퍼프
5. 남아서 흩어지는 검은 연기

이 카메라 거리에서 타격이 읽히는 이유는 **3번 흰 링**이다. 얇고 대비가 극단적이라
주황 바닥·회색 바닥·불길 앞 어디에서도 보인다. 색으로 승부하지 않고 **명도 대비**로 이긴다.

우리 `combatVfx.ts` 에는 링 레이어가 없다. 추가 비용이 가장 싸고 효과가 즉시 보인다.

### C. 플레이어가 배경보다 **어둡고**, 액센트만 발광한다

`ref/moon-01-environment.jpg`

메크는 거의 검은색이고 빨간 발광 띠만 있다. 밝은 주황 바닥 위에서 실루엣이 즉시 읽힌다.
우리는 캐릭터도 바닥도 똑같이 조명을 받아 **대비가 낮다** — 밝은 톤으로 바꾼 뒤 더 그렇다.

→ 캐릭터 기본 톤을 낮추고 무기날·눈·문양에만 발광 액센트를 준다.
"밝고 아기자기한 분위기" 라는 확정 방향과 충돌하지 않는다 — 배경은 밝게 두고
**캐릭터만 배경보다 한 단계 어둡게** 하는 것이다.

### D. 환경이 곧 광원이다

`ref/moon-01-environment.jpg`, `ref/moon-05-hud.jpg`

용암 도랑이 실제로 방을 물들인다. 단일 태양광 + 앰비언트로는 나오지 않는 응집력이다.

우리는 횃불을 발광 머티리얼로만 처리했다(광원 30개를 피하려고). **그 판단은 유지한다.**
대신 방 하나를 물들이는 **큰 광원 하나**를 쓴다 — 용암 균열·화로·마법진 같은 구역 광원.
광원 **개수**가 아니라 **크기**가 만드는 그림이다.

### E. 수직 구조물이 바닥면 위로 선다

철골 가설물이 서 있고 다리가 용암 위를 지난다. 가림과 깊이가 생긴다.
우리 던전은 벽만 있는 평면이라 위에서 보면 납작하다.
소품 배치는 이미 있으니 **키 큰 구조물 한 종류**만 추가해도 크게 달라진다.

### F. 팔레트가 사실상 2색

주황(불) + 채도 낮은 회청색. 나머지는 전부 그 둘의 명도 변주다.
`theme.ts` 가 이미 팔레트 구조이므로, **존별 2색 규칙**을 강제하면 응집력이 붙는다.

## 옮기지 않을 것

- 메크 실루엣, `열`(heat) 자원, 총기 연출 — 장르가 다르다.
- 저 카메라는 우리보다 각도가 낮고 가깝다. 우리는 Z/X·휠로 이미 조절되므로 **기본값만** 재검토한다.

## PM 확인이 필요한 것 (아트가 아니라 제품 결정)

### ① 밀도

처치 카운터가 22초 동안 **983 → 1108**. 초당 약 5.7킬이다. 적은 플레이어보다 훨씬 작고,
화면에 수십 마리가 동시에 있다. 서바이버류에 가까운 밀도다.

우리 갱도는 잡몹 18마리다. **이 밀도가 목표라면 전투 설계를 다시 잡아야 한다** —
적 체력·처치 보상·광역 스킬 비중이 전부 달라진다. 아트 작업이 아니다.

### ② HUD 를 얼마나 비울 것인가

`ref/moon-05-hud.jpg` — 저쪽 HUD 는 이게 전부다:

| 위치 | 내용 |
|---|---|
| 최상단 | 얇은 초록 경험치 띠(가로 전체) |
| 좌상단 | 시간 · 처치 수 · 레벨 |
| 좌하단 | 장갑(파랑) · 열 · 능력 슬롯 5칸 |
| 우상단 | 메뉴 |

**미니맵이 없다. 데미지 숫자가 없다.** 피드백을 전부 VFX 로 준다.

우리는 데미지 숫자 + 미니맵 + 패널 2종이 있다. 지우자는 게 아니라,
**기본 상태를 더 비우고 토글로 돌리는** 선택지가 있다는 뜻이다.

## 내 작업 순서 (시각 레인)

1. 바닥 명암 띠 — 비용 0
2. 타격 흰 링 레이어
3. 캐릭터 톤 ↓ + 발광 액센트
4. 구역 광원(큰 것 하나)
5. 키 큰 수직 구조물
6. 존별 2색 팔레트 강제

각 단계는 `npm run shots` 대조 시트로 전후를 비교한다. 그게 이 계약의 용도다.
